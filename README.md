# ImageKomb

ブラウザ上で動く画像変換ツール

## 使い方

1. [ImageKomb](https://hobione2k.github.io/ImageKomb/)または`index.html` をブラウザで開く（サーバー不要・画像は外部に送信されません）
2. 出力形式・品質・背景色を選ぶ
3. 画像をドラッグ＆ドロップ（またはクリックして選択）すると変換されます
4. 各行の「ダウンロード」または「すべてダウンロード」で保存

## 対応形式

ブラウザ標準機能のみで変換するため、対応形式はブラウザに依存します。

* 入力: ブラウザが表示できる形式（BMP / JPEG (jpg, jfif, jif) / PNG / GIF / WebP / AVIF など）
* 出力: ブラウザが書き出しに対応している形式のみ選択肢に表示（PNG / JPEG / WebP、ブラウザによっては AVIF 等）
  * GIF・BMP の書き出しは主要ブラウザが標準で対応していないため、通常は選択肢に表示されません

## 補足

* アニメーション GIF / WebP は先頭フレームのみ変換されます
* JPEG など透過非対応の形式では、透過部分を指定した背景色で塗りつぶします

## ディレクトリ構成

```text
index.html        画面
css/style.css     スタイル
js/converter.js   画像の読み込み・変換処理
js/app.js         画面制御（ドラッグ＆ドロップ、結果一覧）
docs/spec.md      仕様
```
